## KEY FINDINGS — EXAM STRATEGY INSIGHTS

### 1. The Binary Question (Q1) Is Always Worth 11–13 Marks
Every single paper opens with binary/number representation. Topics covered every time:
- Denary ↔ binary conversion
- Binary ↔ hexadecimal conversion
- Binary shifts (left and right)
- Binary addition (2023, 2024 onward)
- Units of data (KB, MB, GB, TB comparisons)
- Colour depth / unique values calculations
**Mastering all binary skills alone is worth ~15% of the paper.**

### 2. The Networks Question is the Biggest Section
Networks consistently earns 12–20 marks per paper. Sub-topics rotate but always include:
- LAN characteristics / comparison with WAN
- Wired vs wireless benefits and drawbacks
- Protocol identification (HTTP, HTTPS, FTP, IMAP, POP, SMTP)
- Why protocols use layers
- Network hardware (router tasks / switch role)
- IP address format (IPv4/IPv6 getting more attention in 2024)

### 3. Every Paper Has Exactly One 8-Mark Extended Response
This is the only question using Levels of Response marking. It always:
- Uses a * marker
- Asks you to "discuss the positive and negative" impacts
- Provides bullet points to structure your answer
- Covers legal, ethical, privacy, or environmental angles
- Changes scenario every year (AI, facial recognition, open source, manufacturing)
**High-scoring answers: use both sides, use technical vocabulary, explicitly reference bullet points given, contextualise to the scenario.**

### 4. CPU and Systems Architecture Is Always Present But Rotates Depth
- CPU performance factors (clock speed, cache, cores) appear in all papers
- Fetch-execute cycle appears in depth in 2024 and Specimen; lighter in 2022/2023
- Registers (PC, MAR, MDR, ALU, ACC) appear in 2022 and 2024 as table completion
- Embedded systems appear in 2023, 2024, and likely 2025

### 5. Systems Software (OS + Utility) Is Growing in Prominence
- 2023: utility software (1 mark only), open source/proprietary (6 marks)
- 2024: OS functions table (4 marks) + utility gap fill (6 marks) + open source (8 marks)
- 2025: OS functions + utility (9 marks combined)
**Expect OS functions + utility software to continue as a guaranteed section.**

### 6. Network Security Alternates in Depth
- Specimen: 12 marks (very detailed protection and errors)
- 2022: 10 marks (physical + software security, legislation)
- 2023: 7 marks (threats tick table + describe a threat)
- 2024: Embedded in network section (not a standalone security Q)
- 2025: Part of networks section

### 7. Topics That Have NEVER Appeared as Direct Questions
- Packet switching and packet structure
- Full TCP/IP model layers by name (Application, Transport, Internet, Link)
- File systems (FAT, NTFS)
- BIOS / boot process in detail
- Pipelining / parallel processing
- Interrupts
- Health and wellbeing impacts of digital technology (though hinted in ethical Qs)
- Specific encoding: Huffman coding, RLE (mentioned in marking guidance but never asked directly)
- Satellite, cellular, or fibre connection types for WAN

### 8. The "Justify Your Choice" Secondary Storage Question Is a Fixed Template
Always: identify a type (magnetic / solid state / optical) THEN justify with multiple points matching the scenario. Look for:
- Capacity needs (large audio/image files = magnetic or SSD)
- Portability (laptop/mobile = SSD)
- Durability (moving device = SSD, no moving parts)
- Speed (professional use = SSD)
- Cost (budget = magnetic)
Justification must match the scenario to score full marks.
